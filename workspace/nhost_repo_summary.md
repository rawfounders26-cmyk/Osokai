# Nhost (nhost/nhost) — Repo Summary

Open-source Firebase alternative with GraphQL. MIT license.

## Stack
- PostgreSQL (Database)
- Hasura (Instant GraphQL API)
- Nhost Auth (Authentication)
- S3-compatible Storage
- Node.js serverless functions (JS/TS)
- Nhost CLI for local dev
